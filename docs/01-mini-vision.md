# Chatter: a playful real-time chat app

## Objective
Build a real-time chat application to learn Socket.IO, Node.js, Express, and modern frontend patterns.

## Core Motivation
This is fundamentally a learning project and a portfolio piece. The goal is to build a practical understanding of WebSocket-based real-time communication, event-driven architecture, theming, and responsive design.

## Key Focus Areas
1. **Real-time bidirectional communication**: Mastering Socket.IO for instant data transfer.
2. **Modern, beautiful UI**: Crafting a clean interface with dark/light theming and dynamic accent colors.
3. **Responsive design**: Ensuring a seamless experience across desktop and mobile devices.
4. **Progressive enhancement**: Starting simple (Plain JS) and evolving the stack (TypeScript → PostgreSQL) in well-defined phases.

## Success Criteria
- Multiple users can connect and chat in real-time without noticeable latency.
- Users can clearly see who is currently online in the sidebar.
- Typing indicators provide immediate feedback when others are drafting messages.
- Users can toggle between light and dark themes, and their preference is saved.
- The layout adapts gracefully to mobile screens.

## Non-Goals
*Explicit, defensive scoping to keep the initial project focused and achievable:*
- No authentication/login system (just a simple username prompt).
- No private/direct messages (Phase 1).
- No multiple chat rooms/channels (Phase 1).
- No file or image sharing.
- No message editing or deletion.
- No end-to-end encryption.
- No push notifications.
- No video or voice chat.
